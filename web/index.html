Contribuição das árvores na primeira transação

Cada barra é o score de uma árvore. O scikit-learn calcula a média desses scores. A comparação com o limiar produz o alerta.

Score sem calibração. Um score de 0,8 não comprova 80% de chance de fraude no mundo real. O alerta indica revisão humana. V1 a V28 são componentes de PCA sem significado comercial disponível.

AP significa Average Precision. Acurácia isolada oculta os erros na classe rara. As métricas são da classe fraude, no limiar 0,50.

Permutação mede quanto a AP cai ao embaralhar uma variável. A importância representa dependência preditiva nesta avaliação, sem estabelecer causa ou explicar a decisão de um caso individual.

Os casos em que o modelo falhou

São transações reais da validação. Um falso negativo deixa uma fraude passar. Um falso positivo envia uma transação legítima para revisão.

Um modelo condicionado aos dados

  • A base contém dois dias de setembro de 2013. A divisão aleatória não demonstra desempenho futuro.
  • Há poucas fraudes e não há identificação de titulares para separar cartões entre conjuntos.
  • Os componentes de PCA foram fornecidos prontos. O escopo do ajuste original é desconhecido.
  • Os scores não foram calibrados. O protótipo não aceita dados brutos de compras sem a mesma transformação.
  • Os intervalos de confiança medem incerteza amostral nesta divisão. Não incluem mudança dos padrões nem variabilidade entre novos treinos.

Desafio para a plateia

Escolha um falso negativo, reduza o limiar e observe se passa a gerar alerta. Depois teste uma entrada nova. O grupo deve explicar por que alterar somente Amount não garante que uma transação seja fraudulenta.
